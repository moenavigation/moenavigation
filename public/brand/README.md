# Moe Navigation Co.,Ltd. logo

The logo is vectorized from the supplied `Moe Logo - 2026.png`. It replaces the previous draft M-and-wave identity.

- `moe-logo.svg`: transparent, closely cropped artwork for the website (805 × 365 viewBox).
- `moe-logo-original-canvas.svg`: the same paths with the original 831 × 464 canvas and margins.
- `src/app/icon.svg` and `src/app/favicon.ico`: the same logo on a white backing for browser tabs.

The lettering and waves are outlined paths with no font or embedded bitmap dependency. The red (`#DA151D`) and navy (`#164378`) are sampled from the supplied image. Raster noise is removed; the letter shapes, wave contours, and original proportions are retained.

Render with automatic height. Use a white backing on dark surfaces to keep the original colors visible. `BrandMark.tsx` is the shared website component. Keep company/legal names and accessible link labels as text.
